# 排布（Arrangement）的新范式调研

> 2026-10-06。目的：**跳出「数据学习 + 元启发式」这条谱系**，找"怎么排布"本身的
> 新方法论 —— 而且要是**现有算法目录里没有的**东西。
> 每节都给出：核心思想 · 公开证据 · 对本项目的具体落点 · 诚实的边界。

## 0. 先认清现状：我们已经在用的四类，都属于"已知目录"

| 类别 | 本项目里的实例 | 为什么再堆同类的边际收益已很低 |
|---|---|---|
| 元启发式 | GA / LNS / MNSA / ALNS / Fix-and-Optimize | 都靠「邻域移动 + 接受准则」；受**相位顺序**与邻域设计支配 |
| 精确/CP | Timefold 约束求解、匈牙利分道 | 规模一大就退化，只能局部用 |
| 构造式 | 蛇形款型、贪心着色、字典序元组 | 一次性决策，**早提交早丢弃** |
| 学习式 | 那 16 个 MoE / 主 MoE | 学的是「已有搜索器」的先验，**不产生新搜索结构** |

真正的瓶颈不是"搜得不够久"，而是：
**① 相位顺序（先做谁的决定，后面的就再也回不去）；② 邻域与算子的想象力上限。**

下面四条，全部绕开这两点。

## 1. 差异理论 / 低差异序列 —— 把"均衡"从"搜出来"变成"构造出来"

**核心思想**：不再"希望搜索能收敛到均衡"，而是用**带误差上界的构造**直接给出均衡排布。

- **Holroyd–Propp 定理**：给定有限集上的概率分布 π，存在无穷序列 s₁,s₂,…
  使得对**任意** k 和任意 s，都有 `|N_k(s) − kπ(s)| ≤ 1`。
  即：**任意前缀的偏差不超过 1**，而且是**增量式**的（加新元素不用重算）。
  这不是启发式，是**硬保证**。后续 Angel–Holroyd–Martin–Propp 给了显式算法。
- **2025 年的突破（Bansal–Jiang）**：单位向量集合的差异可做到 `(log N)^{1/4}`，
  是 Komlós 猜想上限**近三十年来第一次实质性收紧**，且**算法高效、可构造**。
- **拉丁方 + 差异下界**：LSBGO（IEEE 2025）用拉丁方做云任务分配，并援引 Schmidt 的
  结果给出 `disc(L_m) ≥ C·log m` 下界 —— 即"用拉丁方能大幅降低差异，但存在
  **对数级的下界**，不可能做到零差异"。这条界本身对需求定义就有指导意义。

**对本项目的落点**（这里痛点全是"铺匀"）：
- 道次公平（同班用各道次数）→ 直接套 Holroyd–Propp：以"班级"为 S，
  以"该班在各道的目标比例"为 π，得到一个**偏差 ≤1** 的道次序列。
- 裁判 / 班主任派遣均衡 → 同上，S = 裁判，π = 期望承担比例。
- 休息间隔分散、班级项目分散在整天内 → 低差异序列（van der Corput / Halton）
  本来就是"在任意子区间里都铺得均匀"的构造。
- **与现状的差别**：现在是"算完再检查均不均"，改后是"**构造上就不可能不均**"。

**边界**：差异理论管的是"铺匀"，不管"可行性"。所以它是**约束满足的补充**，
不能替代可行性判定 —— 应当嵌在"候选集已合法"之后（正好对应现有的
`candidatePlacements` 过滤之后那一层）。

## 2. e-graph / 等式饱和 —— 一次性消除"相位顺序"

**核心思想**：改写是**非破坏性**的。传统优化"选一条路走到底"，e-graph 把
**所有等价形式同时存下来**，直到最后 extraction 阶段才决定要哪一个。
（egg / egglog 体系，提取最优代表是 NP-hard，实用上走代价引导或 treewidth 精确解。）

**证据**：
- `SkyEgg`（arXiv 2511.15323）把**变换 + 映射 + 调度统一成同一张 e-graph 上的改写规则**，
  再把饱和后的调度问题整成 ILP 求解；对比商业 HLS 工具提速 3.12×。
  它的关键洞察是：**顺序做"变换→调度→映射"会提前剪掉大量组合**，
  而 e-graph 把三者放到同一层同时暴露。
- 并行化突破（CC 2026，McGill）：线程安全数据结构 + 延迟 e-graph 更新，
  比 egglog 快 16× 找到更优 idiom。

**对本项目的落点**：
把"**代价中性的等价重排**"写成改写规则，例如
`交换两个互不冲突项目的时段` / `同一项目内换组次` / `同组内换道` /
`跨时段拆分↔合并` —— 这些在业务上**等价可行**，但代价不同。
饱和之后用现有 `metrics.py::WEIGHTS` 做 extraction。
**价值**：现在的链式搜索（GA→LNS→MNSA→ALNS→Fix-opt）每一步都在提前提交；
e-graph 是唯一能把"所有等价形态"留到最后统一比价的已知框架。
**边界**：需要定义"哪些改写在语义上等价"（这一步是领域知识，必须人写），
且要注意饱和规模爆炸（需设节点上限 / 迭代上限）。

## 3. LLM 驱动的"方法发现"（FunSearch → EoH / ReEvo / VRPAgent → AlphaEvolve）

**这一条最需要澄清**：它不是"训练一个模型来输出排布"。
结构是 **LLM 生成代码 + 自动评测器打分 + 进化维护种群**；
LLM 只当"变异算子"，**评测器负责消灭幻觉**，最终产物是一段**可读、可审计、无神经网络的程序**。

**它真的产出过"文献里没有的算法"**：
- **装箱（bin packing）**：发现的新启发式把超额箱数压到 **0.03%**，
  而 first-fit 4.00% / best-fit 3.79%。且规则**反直觉** ——
  "只在非常紧的时候才塞紧缝，否则优先选**更空**的箱"，以避免留下填不上的小缝。
- **VRPAgent（2025）**：为 **LNS 自动生成问题专用的 destroy/repair 算子**，
  成为**首个在车辆路径标准基准上推进 SOTA 的 LLM 方法**。
  ← 这与本项目 `opt.alns`（手写 4 破坏 + 2 修复）是**同一个位置**。
- **EoH（Evolution of Heuristics, 2024）**：同时进化启发式的**自然语言"想法"与代码**，
  在多个组合问题上超过 FunSearch 且 LLM 调用少得多。
- **ReEvo（NeurIPS 2024）**："verbal gradient" —— 让 LLM 对比两个启发式并用自然语言
  说出哪里该改，比 FunSearch 样本效率高一个量级。
- **AlphaEvolve（DeepMind 2025）**：进化**整个代码库**；成果包括
  4×4 复矩阵乘法 **48 次标量乘**（56 年来首次改进 Strassen 的 49），
  以及一个部署在 Google 数据中心、**长期回收 0.7% 全球算力**的调度启发式。

**对本项目的落点**：本项目**已经具备全部前提条件**：
- 有**快速确定性评测器**：`sports_ai/metrics.py::WEIGHTS` + `scorer`（毫秒级、无副作用）。
- 有**明确的骨架**：ALNS 的 destroy/repair、GA 的交叉/变异、选择器
  `capacityFeasible ∧ cliqueFeasible` —— 这些正是"用代码写死的领域假设"，
  恰好是 LLM 变异最有价值的位置。
- 有**可复现的评测集**：现有 scenario 生成器（五档 HELL/REGULAR/BLOCK/LANE/TEAM）。
⇒ 可以直接对标 VRPAgent：**让 LLM 进化 destroy/repair 算子族**，
基线就是现有手写的 4+2，判据是"在同一评测集上加权代价更低"。

**边界（诚实说）**：需要 LLM 调用预算；进化出的算子要人工审阅（可读但未必直观）；
对"评测慢"或"评测有噪声"的问题不适用 —— 好在我们的评测既快又确定。

## 4. 热带（max-plus）代数 —— 给"已定的排布"做体检与瓶颈定位

**核心思想**：把 max 当"加"、把普通加当"乘"，得到热带半环。定时事件图
（timed event graph）在这种算术下是**线性系统**：
`x(k+1) = A ⊗ x(k)`（Baccelli《Synchronization and Linearity》1992）。
于是线性代数全套工具都有热带版本：**特征值 = 周期（cycle time）**、
特征向量 = 稳态节奏。

**证据与关键边界**（引一篇 2026 年的教学专著，它把话说得很准）：
热带代数**非常擅长"把时间沿一个已选定的结构传播、并定位瓶颈"**，
但**它本身不解决"选哪条路/哪个指派/哪个顺序"这个组合难题**。

**对本项目的落点**（当诊断器用，成本极低）：
- 对一个**已排好的方案**，用 max-plus 传播算出精确工期，并给出**关键环
  （critical cycle）** —— 即"究竟是哪一条约束链决定了总时长"。
- 这类信息现在的代价函数**给不出来**：`PlanCost` 只给一个数，
  而 max-plus 给的是**瓶颈的拓扑位置**（哪几个项目→哪个场地→哪一天首尾相接卡住了）。
- 周期性赛程（每天重复的节奏）下，特征值直接给出稳态周期，可用于回答
  "再多加一天能不能压下来"这类问题 —— 比再跑一次 GA 便宜得多。

**边界**：只分析、不搜索。定位是**和现有搜索器互补**，不是替代。

## 5. 精确路线的另一极：热带张量网络 + 分支定界（BBTN）

**核心思想**：把组合优化写成**张量网络收缩**，在热带半环下做**精确**基态求解；
再用分支定界控制爆炸的空间复杂度。

**证据**：BBTN（arXiv 2602.05470，2026-02）在 ±J 自旋玻璃上做到 64×64 的
**精确基态计数**，在 100×100 King 子图上解 Maximum Independent Set，
**比主流整数规划求解器快 30 倍以上**，并把标准热带张量网络的运行时间
"从数年压到分钟"。

**对本项目的落点**：本项目的**兼项冲突图着色 / 道次冲突**在形式上接近
MIS / Potts 模型 —— 小规模实例（单项目、单组次）理论上可以走"精确"路线，
拿到**可证明最优**的局部解，再用它去校准启发式的差距。
**边界**：研究级工具链，工程化成本高；只适合作为**局部精确子求解器**，
不宜做主链路。列为备选，不列为近期目标。

## 6. 我的排序（按"对本案的可落地性 × 概念新颖度"）

| 优先级 | 范式 | 理由 | 预计落点 |
|---|---|---|---|
| **P0** | 差异理论 / 低差异序列 | 痛点全是"铺匀"，且这是**构造+硬保证**，不是又一次搜索；实现量最小 | 道次公平、裁判/班主任派遣、休息间隔分散 |
| **P0** | FunSearch/EoH 式**算子发现** | 本项目评测器已就绪、算子位置明确、有 VRPAgent 正面先例 | 用 LLM 进化 ALNS 的 destroy/repair 族 |
| **P1** | e-graph 等式饱和 | 唯一能正面解决链式搜索"相位顺序"的已知框架 | 把"代价中性等价重排"写成改写规则 |
| **P2** | 热带代数（max-plus） | 便宜、纯诊断，能给出**瓶颈拓扑**这类现有代价函数给不出的信息 | 关键环定位 / 周期分析 |
| **P3** | 热带张量网络 + BnB | 精确但工具链重 | 局部精确子求解器（备选） |

## 7. 一个必须说明的共同前提

**这四条里，只有 P0/P2 不依赖"快速确定性评测器"；P0 之外的搜索类方法全都依赖它。**
本项目恰好有一个：`sports_ai/metrics.py::WEIGHTS` ↔ Java `plan/PlanCost` 的
加权代价（毫秒级、确定性、与训练/推理解耦）。
**这是本项目做"算子发现"类工作的最大结构性优势** —— 多数团队卡在"没有廉价评测"。
