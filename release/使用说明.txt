运动会智能编排系统 v2.8.7 —— 发布包使用说明
============================================================

本目录是「嵌入式版」：前端静态资源与 16 个 ONNX 模型全部在 jar 内，
外加一份便携 JDK，**解压即可运行，目标机器无需安装 Java**。

------------------------------------------------------------
一、目录内容
------------------------------------------------------------
  sports-2.8.7.jar          主程序（内含前端 + 16 个模型，约 736 MB）
  start.bat / start.ps1     启动程序（优先使用随包 JDK）
  jdk-21.0.12.1+1\          便携 JDK 21（免安装）
  external-models\          外置模型版（自成一包：同样自带 JDK + models 目录，可选）
  使用说明.txt              本文件

两个版本各自带一份 JDK，**可以单独拷走分发**，互不依赖。
启动程序查找 JDK 的顺序：本目录 → 上级目录 → JAVA_HOME → 系统 PATH。

启动后会在本目录生成（首次运行）：
  data\                     配置与数据目录（含 app-config.json）
  sports_meet.db            SQLite 数据库（默认数据源）

------------------------------------------------------------
二、启动
------------------------------------------------------------
Windows 双击 start.bat，或在 PowerShell / CMD 中：

  .\start.bat
  .\start.ps1                       默认端口（跟随 data\app-config.json，兜底 8080）
  .\start.ps1 -Port 8899            指定端口
  .\start.ps1 -Port 8899 -Host ::   指定绑定地址（-Host 是 -BindHost 的别名）
  .\start.ps1 -Xmx 2g               指定最大堆

启动后浏览器打开 http://localhost:8080 （端口以实际输出为准）。
停止：在运行窗口按 Ctrl+C。

JDK 查找顺序：本目录 → 上级目录 → JAVA_HOME → 系统 PATH。
随包 JDK 若缺失，会打印 [WARN] 并退回 PATH 中的 java。

------------------------------------------------------------
三、关于模型（重要）
------------------------------------------------------------
16 个 ONNX 模型已打进 jar，**不需要**额外配置模型目录。
若启动日志出现「模型不存在 / 回退规则编排」，说明 jar 不完整或文件名被改动。

要更换模型而不重新打包，用本包里的另一份：
  external-models\          外置模型版（jar 不含模型，从外置 models\ 读取）

------------------------------------------------------------
四、常见问题
------------------------------------------------------------
Q：双击 start.bat 一闪而过？
A：多半是端口被占用或 JDK 缺失。请在 CMD 里手动运行以看到完整报错。

Q：想换端口 / 换数据库 / 迁移到 MySQL？
A：在网页「设置」里改即可（支持 SQLite / H2 / MySQL 热迁移，无需重启）。

Q：怎么确认 AI 能力真的生效？
A：编排页的「算法详情」会回显精修链各环节的回执；AI 模式还会显示模型来源与自对抗轮数。
   若显示「不可用（已降级）」，检查启动日志里的模型加载记录。

------------------------------------------------------------
五、校验信息
------------------------------------------------------------
  版本        2.8.7（jar 内 META-INF/MANIFEST.MF 的 Implementation-Version）
  模型清单    sports-ai/models/MANIFEST.json（源码仓库内，逐模型记录 sha256 + 用途）
  自检命令    java -jar sports-2.8.7.jar -h      只打印帮助并退出，不启动服务
